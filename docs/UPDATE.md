# 更新文档

这份文档用于集中说明近期版本变更、升级关注点，以及发版时的推荐检查项。

## 最近一轮重点改动

### 终端与实例操作

- 维护终端升级为多会话 PTY 工作台，支持创建、切换和关闭多个会话
- 终端页新增主题切换、快速命令和更稳定的窗口尺寸同步
- 实例操作页与维护终端进一步解耦，运行日志与交互终端职责更清晰
- 实例停止改为优先发送 Ctrl+C，中断失败时再执行强制停止

### WebUI 主题系统

- 新增多套 WebUI 主题风格与主色配色切换
- 支持 `Classic`、`Frost`、`Paper`、`Midnight` 四套界面主题
- 支持亮暗模式手动切换与“主题跟随系统”
- 修复手动切换主题后刷新页面又回退的问题
- 修复设置抽屉被终端、图表等页面元素遮挡的问题

### 关于页与文档入口

- 新增关于页，集中展示项目介绍和文档入口
- 补齐使用文档、部署文档、更新文档的稳定入口
- 修复关于页中指向不存在分支导致的 404 问题

### Docker / NAS 部署体验

- 去掉会误导 NAS 面板自动生成挂载项的默认 `VOLUME`
- 保留更明确的挂载说明，降低路径映射误配概率
- 文档补充 `/projects`、`/external-projects`、`/opt/nonebot-projects` 的职责说明

### 实例管理与运行

- 添加实例失败时会自动回滚实例记录，避免污染 `project.json`
- 实例列表针对别名路径做去重，减少重复实例
- 将实例操作页与独立维护终端拆分，职责更清晰

### 安全与登录

- 会话过期时长与永久 token 持久化逻辑拆分得更明确
- 浏览器会话依赖 JWT，有效期由安全设置控制
- 永久 token 仍由配置文件持久化，不因浏览器会话变化而直接失效
- 永久 token 修改后会生成新的登录链接，便于直接跳转登录页并带入凭证

### Playwright / htmlrender 场景

- 启动实例前会优先尝试补齐 Chromium
- Docker 镜像内补齐了常见 Linux 依赖
- 更适合 NAS / Docker 下依赖浏览器的插件运行

## 升级前建议确认

升级前建议至少确认下面这些点：

1. 当前 `config.json` 和 `project.json` 已备份
2. 你使用的是显式镜像版本，而不是长期漂移的旧容器
3. 外部实例挂载路径仍然对应容器内路径
4. 如使用永久 token，认证配置字段没有被误删
5. 如依赖 Playwright，升级后重建的是新镜像而不是旧缓存

## 升级后建议回归检查

升级完成后建议快速检查：

1. 能否正常登录
2. 实例列表是否完整且无重复
3. 当前实例能否启动、停止、查看日志
4. 终端页是否能正常建立会话
5. 文件管理、扩展管理和安全设置接口是否正常

## 发版建议

发版时建议同步核对这些文件：

- `pyproject.toml` 中的版本号
- `Dockerfile` 中的 `APP_VERSION`
- 这份更新文档中的版本说明

推荐步骤：

1. 本地测试通过
2. 更新版本号
3. 提交代码
4. 打对应版本 tag
5. 推送 `master` 和 tag

示例：

```bash
git add .
git commit -m "feat: your change"
git push origin master

git tag v0.4.8
git push origin v0.4.8
```
